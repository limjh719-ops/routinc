# ROUTINC (루틴크)

**운동의 기록을 넘어, 소통까지.**

ROUTINC는 트레이너와 회원을 위한 **양방향 운동 커뮤니케이션 플랫폼**입니다. 정해진 루틴을 일방적으로 전달하는 앱이 아니라, 운동·식단·컨디션 기록에 질문과 피드백을 연결하고 트레이너의 회원 관리 시간을 줄이는 것이 목표입니다.

## 현재 상태
- 제품 기획 / MVP 설계 단계. 애플리케이션 코드는 아직 없습니다.
- [제품 요구사항 및 화면 설계](docs/PRODUCT_SPEC.md)
- [Codex 첫 개발 지시서](docs/CODEX_START.md)

## 핵심 원칙
1. **양방향**: 회원과 트레이너 모두 기록별 댓글과 일반 메시지를 작성할 수 있습니다.
2. **맥락 보존**: 스쿼트 피드백은 해당 스쿼트 기록에 연결되어 남습니다.
3. **사생활 분리**: 전화번호·카카오톡 친구 추가 없이 초대 링크로 연결합니다.
4. **업무 효율**: 트레이너의 미답변 질문을 한눈에 모아 보여줍니다.
5. **프라이버시**: 회원 기록은 권한이 있는 회원·담당 트레이너만 확인합니다.
6. **AI는 보조**: AI가 단독으로 운동·식단·건강 판단을 내려 회원에게 발송하지 않습니다.

## 개발 방향
- 모바일 우선 반응형 웹앱
- Next.js + TypeScript + Tailwind CSS + Supabase (제안 기술)
- 코드 시작은 `docs/CODEX_START.md`를 따라 작은 단계로 진행
- 공개 저장소에 실제 회원 정보, API 키, 비밀번호, .env 파일을 올리지 마세요.
